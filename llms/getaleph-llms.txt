# Aleph (Getaleph)

> Aleph is an AI-native financial planning and analysis (FP&A) platform that automates finance busywork so teams can focus on strategic work. It consolidates data from 150+ ERP, CRM, and HRIS integrations, syncs live data into Excel and Google Sheets, builds interactive dashboards, and exposes governed financial data to AI tools through the Aleph Agent and a hosted Aleph Agent MCP server.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public getaleph.com site and repo artifacts. Aleph does not currently publish a public REST OpenAPI or developer portal; developer access is provisioned through the app and MCP server.
